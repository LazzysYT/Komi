# Reporting a security concern / Сообщить об уязвимости

KomiAnime: https://komianime.online

Please do not post exploit details, credentials, personal data or access tokens in public GitHub issues, chats or comments. Use GitHub's private vulnerability reporting option in this repository if it is available. Otherwise, use the project's [contact page](https://komianime.online/contacts) to request a private channel with an administrator before sending technical details.

Include the affected URL, a concise description, minimal reproducible steps, impact, and a way to contact you privately. Redact all personal data and secrets. Stop testing immediately if you encounter data belonging to someone else.

This policy does not authorize denial-of-service, credential stuffing, accessing other users' accounts, destructive testing, or testing third-party services. Do not conduct load tests against production without separate written authorization.

Copyright and other legal notices are distinct from security reports. The contact page can be used to request the appropriate private contact; formal statutory notices and consumer rights remain unaffected.

We do not require a reporter to waive statutory rights. No bounty or response time is promised by this policy.
