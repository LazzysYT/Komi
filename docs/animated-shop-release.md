# Animated shop — preview candidate

This branch introduces six visible cosmetic rarity tiers, twenty new cosmetics (including twelve original vector avatar ornaments) and four three-item themed looks. Prices are proposed, using current 15–120 AC price points as the reference. Existing item prices stay unchanged. Set prices are the sum of server-verified individual products, excluding already-owned products; no unverified client-side discount.

New items are available for preview on non-production hosts. On production they stay hidden from new sales until the authenticated server returns the additional animated catalog revision. Existing sales retain the original living revision gate. The SQL in animated-shop-catalog.sql is a candidate, not a migration that has been run. Use a disposable staging database and the official migration tooling to verify the constraint extensions and create a tracked migration before production. Test purchase, equip, insufficient balance, cart cancellation, repeat purchase, account switch, public profile hydration, reduced motion, mobile layout, and no retired product restoration.

Not included in this first increment: independent equip slots for avatar-only effects, entry animations, character auras, comment reactions, or Party join effects. These require authenticated server ownership and explicit render hooks in collection/comment/Party code; the existing retired reaction products must not be silently restored. Guest visibility of new cosmetics on the primary domain requires a future public, read-only revision mechanism or coordinated release change; until then only authenticated users with confirmed catalog pricing see the additions.
