# Animated shop — release candidate
28 new items, six rarity tiers, four sets. Prices use server-verified individual prices, excluding already-owned items. Independent entry/aura/commentfx/party slots are supported by both purchase RPCs. Comment reactions store one public reaction per account/comment; only the owner can change it and only equipped items may be used. Party arrivals are recognized from server presence; collection auras apply to unlocked cards; profile entrances are one-shot with reduced-motion fallback.

The SQL candidate is not yet applied. The public read-only revision RPC enables new inventory after all IDs and prices are confirmed. On non-production hosts preview with /shop?animated_shop=1. The older standalone premium studio excludes the four dedicated effect slots; use the main shop. Existing item prices and retired-item rules remain unchanged. Verify SQL and real authenticated purchase flow before production.
