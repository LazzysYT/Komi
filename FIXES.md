# Проверка и исправления Komi

Проверен клиентский код, браузерные сценарии и существующие SQL-файлы. Изменения ниже касаются клиента; миграции рабочей базы не применялись.

| Ошибка | Исправление |
| --- | --- |
| Закрытие окна просмотра оставляло iframe в DOM: встроенный плеер мог продолжать воспроизведение. | При закрытии содержимое плеера удаляется, для HTML video сохраняется последняя позиция без сброса времени в ноль. |
| Повторное открытие серии сохраняло длительность как 0. | При открытии той же серии сохраняются и позиция, и длительность. При выборе другой серии они сбрасываются. |
| Live/не загруженное видео могло передать Infinity/NaN в прогресс. | Время и длительность приводятся к конечным неотрицательным числам. |
| Любой HTML, начинающийся с iframe, попадал в список доступных источников, даже с javascript: или относительным src. | Источник проверяется через DOMParser и HTTPS URL; атрибуты исходного iframe не переносятся в итоговую разметку. |
| После выхода серверные списки, избранное и история оставались в памяти и могли сериализоваться в старое общее localStorage. Гость также пытался писать общий JSON статусов. | Серверные данные очищаются перед переходом в гостевой режим; гостевая запись общего JSON отключена. Очистка также выполняется при смене Auth-пользователя и исчезновении сессии. |
| Из обработчика Auth вызывались новые Auth-запросы через microtask. | Восстановление вынесено в setTimeout, за пределы обработки Auth-события, чтобы избежать блокировок клиента. |
| Текст чата Watch Party, уведомлений, описания и части метаданных аниме вставлялся как HTML. | Текст экранируется перед вставкой. HTML-сообщение теперь отображается текстом. |
| CI проверял опубликованный сайт, а не изменённый index.html. | Браузерная проверка запускает локальный сервер текущего checkout; добавлены проверки pull request и отдельный регрессионный сценарий. |

## Проверки

- `node scripts/player-regression.cjs`: 17 проверок, включая отсутствие необработанных ошибок браузера. Сеть и Supabase заменены тестовыми ответами; реальные данные не меняются.
- `KOMI_TEST_URL=http://127.0.0.1:8080 node scripts/browser-smoke.cjs`: HTTP 200, формы входа/регистрации, отсутствие ошибок JavaScript и горизонтального переполнения при 1440, 768, 390, 375 px.
- Исходная версия не проходит 11 из 16 функциональных утверждений нового браузерного сценария; исправленная проходит все.
- Для запуска нужен Playwright Chromium; команда установки сохранена в GitHub Actions.

## Границы проверки

Smoke-проверка в этой среде отображала резервные 3 карточки, поэтому она подтверждает работу интерфейса, но не доступность полного облачного каталога. Полный вход через Google, проверка RLS двумя реальными аккаунтами, права Storage и рабочая схема Supabase требуют настроенных тестовых учётных записей. Их секреты в среде отсутствуют. Не утверждается, что все возможные ошибки проекта устранены.
